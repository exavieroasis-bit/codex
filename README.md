# PRIDE browser studio

Open this project in StackBlitz. If it asks, choose **Run this project**, then open **Preview**.

The artwork loads from the project's pinned image files on jsDelivr. The generator runs in the browser; no ZIP, installer, or wallet is required.

For a local preview with Node 18 or newer, run `npm start` and open `http://localhost:3000`. No package installation is required.
